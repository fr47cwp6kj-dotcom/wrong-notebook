# 更新日志

## V1.0.0 - 2026-10-12

- 建立项目文档和 V1 实施路线。
- 增加 Windows 照片收件箱目录初始化脚本。
- 增加受限 SMB 共享配置能力，共享范围仅限 `错题` 目录。
- 增加 V1 环境与上传验收检查脚本。

- 融入“知识单元漏洞诊断”方法论，明确反对机械抄题。
- 增加表层错因与深层漏洞双层分类。
- 增加诊断卡、触发规则、卡点小练和复习原则。
- 增加诊断分类配置与手工知识漏洞卡模板。
- 增加 Agent 诊断行为契约和结构化 JSON 输出要求。
- 增加知识单元库建设、确认、去重和拆分规则。
- 更新 V3-V5 路线：从整题错因记录转向知识单元掌握度。
