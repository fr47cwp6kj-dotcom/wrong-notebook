# iPhone 上传指南（V1）

## 准备

- Windows 电脑已开机并连接家庭局域网。
- iPhone 与电脑连接同一个 Wi-Fi 网络。
- 已在 Windows 上完成 `Initialize-PhotoInbox.ps1` 和 SMB 共享配置。
- 已知电脑局域网地址。检查脚本会列出候选地址。
- 准备一个被授权的 Windows 账户名和密码。

## 连接共享

1. 打开 iPhone 的「文件」App。
2. 点右上角「更多」按钮。
3. 选择「连接服务器」。
4. 输入：

```text
smb://电脑局域网地址
```

把其中的地址替换为 Windows 电脑的实际局域网地址。

5. 选择「注册用户」。
6. 输入被授权的 Windows 账户名和密码。
7. 连接后选择共享 `错因Agent照片`。

## 上传照片

1. 打开 iPhone「照片」App。
2. 选择一张或多张错题照片。
3. 点「分享」。
4. 选择「存储到文件」。
5. 选择已连接的服务器位置。
6. 进入 `初中/待识别` 或 `高中/待识别`。
7. 存储。

第一版不要求重命名、分科或填写说明。拍摄时尽量让一张照片同时包含题干、孩子原答案和老师批改痕迹；如果一张放不下，可以连续拍多张。

## 断开与重连

- 不使用时可以在「文件」App 中断开服务器连接。
- 电脑休眠、关机或更换 Wi-Fi 后，iPhone 无法访问共享。
- 上传失败时，先确认电脑在线、两边同一局域网、账户密码正确，再重试。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到服务器 | 确认 iPhone 和电脑同一 Wi-Fi；在 Windows 运行 `Test-PhotoInbox.ps1` 查看地址 |
| 能连接但看不到共享 | 确认 SMB 共享名和账户权限；避免使用公共网络配置 |
| 登录失败 | 使用完整账户名，如 `电脑名\用户名`；确认账户有密码 |
| 能打开但无法写入 | 确认写入的是 `待识别` 文件夹；重新运行初始化脚本检查 NTFS 权限 |
| 上传中断 | 保留手机照片，恢复网络后重新上传；V1 不做断点续传 |
