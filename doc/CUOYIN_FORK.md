# 错因 Agent 复刻版使用指南

## 入口与数据

本分支以 wrong-notebook v2026.10.26 为基础，保留其上传、校对、题目管理、讲解、练习、试卷、打印、账户和设置功能。新增诊断层不改变原题掌握概率的含义；“知识单元”页单独显示跨题练习结果。

双击项目根目录的 `启动错因Agent.command`，访问 `http://localhost:3333`。仅在本机监听，不自动开放局域网。启动脚本会执行增量迁移，并仅在空库时创建账户和系统标签；已有数据不会重置。使用期间保留终端窗口。

- 默认账户：`admin@localhost`，初始密码 `123456`，首次登录必须修改。
- 数据库：`data/cuoyin-fork.db`；会话密钥在 `.env`，AI 配置在 `config/app-config.json`，均不提交 Git。
- 新安装的官方桌面版与本分支独立运行；下载的 DMG 未被替换。
- 在设置里导出数据可同时保存新增的诊断与小练。恢复这些新增信息需要本分支，原版会忽略新增字段。
- V1 的收件箱照片没有自动迁入。先选择一张照片上传，核对题干和学生作答，再进入诊断。

网页上传、拖拽和替换原题图片支持 JPG、PNG、WebP、GIF、HEIC/HEIF、BMP 和 AVIF，兼容大写扩展名。剪贴板提供图片文件时也可直接粘贴。HEIC/HEIF 会在浏览器本地转成 JPEG 后再裁剪，多图文件只取主图。损坏或无法解码的图片会提示换图或转为 JPG/PNG。Openclaw 批量接口接收 JPEG/PNG。

校对页支持按题号切换，再按「题目 / 答案 / 解析 / 错因」分类查看，默认显示排版预览。长内容、原图与知识点按需展开；修改单题正文会保留其他题目。无法对应题号的内容可从「全文」核对和编辑。保存包含整份识别结果；需要每题成为独立记录时，上传时应使用多题框选。

错题详情题干下方有「SVG 动画讲解」和「交互式图形演示」两个快捷入口。前者点「生成动画讲解」后可播放、暂停或拖动进度条。后者首次先点「开启演示」，再点「生成演示」，可拖动生成图中的可动点或滑块。

## 试用顺序

1. 创建初中或高中错题本，选择学科，上传或手工录入一道错题。
2. 对照原图核对题干和学生原始作答。看不到作答时先补充信息，AI 不猜测。
3. 在题目详情点击“AI 定位漏洞”，或“手工添加诊断”。AI 使用设置中选择的提供商；OpenAI 兼容、Azure、Gemini、Anthropic、MiniMax Code 共用同一诊断契约。
4. 阅读原文证据、首个卡点、未使用条件、触发规则和追问，再选择确认、不确定或不符合。一题可以有多张卡。
5. 确认后复核小练的条件、答案和学段边界，再点击复核按钮。写下判断，对照参考答案自评本次是否独立完成。
6. 在“知识单元”页查看跨题汇总。只看过解析或反复做对同一原题不会变成跨题验证；新的失败或需要提示会中断连续通过。

手工复用单元时可从下拉框沿用名称、触发规则和边界；学段和学科由当前错题本确定，自动隔离。修改题干、作答、答案或解析后，旧卡保留并标记待重新诊断，不再参与当前统计。

## 实现范围

本版落地 V1 方法中的“证据 → 候选漏洞 → 学生确认 → 人工复核小练 → 单元跨题统计”。小练结果由使用者对照答案自评。保留原版按题复习日程；尚未新增按知识单元的到期调度、独立知识单元编辑合并工具或 V1 文件夹自动监听。

AI 识别与诊断效果取决于你配置的模型和真实照片。本地测试不使用个人 AI 密钥；配置后请先用少量真实错题验证。

## 验证命令

```bash
npm run lint
npx tsc --noEmit
npm run test:unit
npm run test:integration
E2E_BASE_URL=http://127.0.0.1:3333 PLAYWRIGHT_CHANNEL=chrome npx playwright test e2e/knowledge-gaps.spec.ts --workers=1 --reporter=list
```

浏览器测试建立独立临时账户，完成后删除该账户及其数据，不使用管理员账户。SQLite 集成测试在系统临时目录运行，覆盖证据校验、事务回滚、用户隔离、学生确认、练习复核、幂等提交、过期诊断、跨题掌握和备份恢复。
