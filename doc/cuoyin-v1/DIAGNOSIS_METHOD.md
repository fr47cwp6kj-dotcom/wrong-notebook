# 知识单元漏洞诊断方法

## 核心立场

错因 Agent 不做电子抄题本。机械誊写题干、追求本子工整，会把时间消耗在“题目外壳”上，却可能没有定位到真正卡住学生的那一小段推理。

系统的默认输出是：

```text
原始照片 -> 步骤拆解 -> 找到卡点 -> 定位知识单元 -> 学生确认 -> 针对性巩固
```

不是：

```text
原始照片 -> 抄完整题干 -> 等待以后重看
```

## 什么是知识单元

知识单元不是教材目录里的宽泛知识点，而是能被学生识别和调用的最小有用组合。

示例：

| 输入信号 | 应调用的知识单元 | 推理结果 |
| --- | --- | --- |
| 等腰三角形 + 底边中点 | 三线合一 | 连中线并判断垂直 / 平分顶角 |
| 二次函数 + 顶点式 | 配方 / 顶点坐标含义 | 确定 symmetry axis 和最值 |
| 数列奇偶项分别递推 | 分奇偶讨论 | 构造两个子数列 |
| 直线与圆相切 | 圆心到直线距离等于半径 | 转化为距离方程 |

同一道题通常由多个知识单元串接而成。学生做不出题，常见情况不是整道题完全不会，而是某个单元没有激活，或两个单元之间的连接没有建立。

## 诊断四问

每道错题至少回答四件事：

1. **卡在哪一步**：从哪一行、哪个条件、哪个图形标记开始，学生无法继续？
2. **漏了什么信号**：题干里哪些词、图形、数值或先前推导结果没有被使用？
3. **缺哪个知识单元**：概念定义、公式适用条件、条件变形，还是单元组合？
4. **下次触发什么就要想起什么**：形成“看到 A + B，想到 C”的调用规则。

学生无法判断时，先记录“不确定”，保留原图和卡点截图，不强行归因。

## 错误层次

错因分为两层，避免把所有问题都笼统写成“粗心”或“不会”。

### 表层错因

用于快速统计行为习惯：

```text
审题漏条件
概念未理解
计算 / 抄写错误
解题步骤跳跃
其他
不确定
```

### 深层漏洞类型

用于决定补什么、练什么：

| 类型 | 含义 | 典型补法 |
| --- | --- | --- |
| condition_signal_missed | 条件信号没有识别 | 条件标注与信号识别训练 |
| concept_definition_unstable | 定义、原理或适用边界不稳 | 复述定义并做正反例判断 |
| formula_condition_misapplied | 公式会用但适用条件错 | 条件判断加变式辨析 |
| unit_connection_missing | 单个单元会，组合不会 | 只练 A + B 的连接步骤 |
| representation_conversion_failed | 文字、符号、图形转换失败 | 三种表示互译 |
| strategy_selection_missing | 不知道选择哪条路线 | 目标导向的路线比较 |
| execution_slip | 计算、符号、单位或转录失误 | 限时小步检查 |
| other / uncertain | 其他或暂不确定 | 人工复盘 |

一题允许多个深层漏洞，也允许暂时没有结论。

## 诊断卡格式

```text
题目照片：
学段 / 学科：
题目来源：

表层错因：
卡住步骤：
没被使用的条件：
涉及知识单元：
深层漏洞类型：
触发规则：看到 __ + __，先想 __
最小巩固练习：
下次复查方式：
学生是否确认：
```

“最小巩固练习”优先针对卡点，而不是整题重做。例如只练 5 道“等腰三角形 + 中点”的辅助线判断，而不是抄写并重做完整几何题。

## AI 输出要求

AI 只能给出候选诊断，必须带证据：

```text
候选卡点：第 3 行把中点只标成 AM = MC，没有继续连接 AD
证据：题干出现等腰三角形和底边中点；图形未作 AD；后续步骤需要垂直关系
候选知识单元：等腰三角形三线合一
候选漏洞：unit_connection_missing
需要学生确认：是否当时没有想到三线合一，还是不知道三线合一内容？
```

禁止输出：

```text
你太粗心了。
你不会几何。
抄写这道题并反复复习。
```

AI 需要区分“没识别信号”“知道单元但没想起来”“不知道单元本身”“知道单元但不会与其他步骤连接”。

## 复习原则

1. 复习对象优先是知识单元和触发规则，其次才是原题。
2. 掌握标准不是“看过”，而是能独立完成同类触发判断或小步推理。
3. 同一知识单元在不同题干外壳中重复出现，避免只记住原题样貌。
4. 连续通过后提高题干外壳变化和干扰条件，检验调用是否稳定。
5. 学习成绩受多重因素影响，本方法不承诺固定提分幅度、名次或时间表。

知识单元本身需要人工维护：名称、触发条件、适用边界、前置依赖和常见误用都要能被学生理解。建设方式见 [知识单元库建设计划](KNOWLEDGE_UNIT_LIBRARY_PLAN.md)。

## 与传统错题本的区别

| 传统抄题本 | 错因 Agent |
| --- | --- |
| 抄题占主要时间 | 照片留存，不抄题 |
| 记录整道题 | 记录卡点、单元和触发规则 |
| 以后重看 | 生成小步巩固与到期复查 |
| 归因常是粗心 / 不会 | 区分表层错因和深层漏洞 |
| 复习原题外壳 | 复习知识单元组合 |
