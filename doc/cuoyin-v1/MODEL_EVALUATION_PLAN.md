# V2 识别评测计划

本计划只定义 V2 前的评测方法，不代表任何模型已部署或验证。

## 评测集

从 V1 收集的照片中挑选样本，先获得家长和学生同意后使用：

| 类型 | 建议数量 | 目的 |
| --- | --- | --- |
| 印刷题清晰照片 | 20 张 | 建立基础基线 |
| 手写清晰照片 | 20 张 | 检查普通手写 |
| 手写潦草照片 | 10 张 | 找失败边界 |
| 数学公式照片 | 15 张 | 检查公式表达 |
| 几何 / 图形题 | 10 张 | 检查图形描述能力 |
| 物理含单位题 | 10 张 | 检查单位与符号 |
| 老师批改重叠照片 | 10 张 | 区分题目、答案、批注 |

每个样本保留人工校对后的标准字段：题干、学生答案、教师答案、解题步骤、第一个卡点、未使用条件、知识单元、表层错因、深层漏洞类型、可读性评级。

## 评测指标

| 指标 | 定义 | 最低要求建议 |
| --- | --- | --- |
| 人工可校对率 | 识别结果是否足以快速修正 | 高于直接重抄 |
| 题干完整率 | 条件和问题没有漏 | 每类不低于 80% 后再试运行 |
| 答案区域识别率 | 学生答案和批改区域可区分 | 需人工审 |
| 步骤切分可用率 | 能区分学生写到哪里、哪里开始卡住 | 需人工审 |
| 漏洞定位命中率 | 候选卡点或知识单元与学生确认一致 | 试运行前建立基线 |
| 单样本耗时 | 从新增文件到候选结果 | 不阻塞日常收集即可 |
| 显存峰值 | 运行期占用 | 低于 12GB 并留余量 |
| 失败可解释性 | 能判断是 OCR、版面还是模型问题 | 必须支持 |

这些指标用于比较方案，不作为提分承诺。

## 候选技术路线

1. 传统 OCR 加版面分析：适合印刷清晰文本，成本低。
2. OCR 加规则后处理：适合公式和单位的初步规范化。
3. 本地多模态模型：适合混合手写、图形和批注，但质量和速度需实测。
4. 混合流水线：OCR 提供文本候选，多模态模型补图形和关系描述。

最终可以组合使用，不做单一路线预设。

## 评测流程

1. 固定同一组样本。
2. 每个候选方案使用完全相同输入。
3. 记录候选输出、人工修改量、耗时、显存和失败原因。
4. 由家长或学生人工评分是否可校对。
5. 由学生确认候选卡点、表层错因和深层漏洞类型。
6. 汇总后再决定是否进入 V2 试运行。

## 明确不做

- 不用学业成绩变化评估 OCR 模型。
- 不把 AI 识别输出直接写入最终答案。
- 不在 V1 阶段下载或启动大模型。
- 不把私有照片上传到不可控在线服务做评测。
