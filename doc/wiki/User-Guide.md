# 错题管理指南

## 创建错题本

创建错题本时选择学段（小学、初中或高中）和学科。本复刻版的数学统一使用浙教版初二上（含必要前置基础），其他学科由学段与学科决定 AI 使用的知识点库，创建后不可修改，建议按学习阶段和学科分别管理。

## 录入题目

| 入口 | 适用情况 |
| --- | --- |
| 图片上传、拖拽、拍照 | 纸质试卷、练习册和已有题目图片 |
| 剪贴板粘贴 | 已复制的截图或图片，使用 `Ctrl/⌘+V` |
| 屏幕截图 | 浏览器支持屏幕共享，且页面满足安全上下文要求 |
| 手动输入 | 已有文字题干，可使用 Markdown 与 LaTeX |
| 直接录入 | 手工整理已知的题干、答案和解析 |

图片可以先裁剪；一张图片上有多道题时，可框选多题批量导入。尽量保留完整题干、必要图形和学生作答，避免模糊或裁掉条件。

网页上传、拖拽和替换原题图片支持 JPG、PNG、WebP、GIF、HEIC/HEIF、BMP 和 AVIF。剪贴板提供图片文件时也可直接粘贴。iPhone 的 HEIC/HEIF 原图在浏览器本地转成 JPEG 后再裁剪，多图文件只导入主图。无法解码时，页面会提示换图或转为 JPG/PNG。

默认图片识别会将题目配图重绘成紧凑的 SVG 示意图，保留解题所需的结构和标注。需要更详细的图时，可在题目详情页点击「AI 重新生成配图」。

单题识别和文字解题后始终先进入校对页，核对题目、答案、错题本后点击保存。解析优先保留 3–5 个关键步骤，错因给出具体下一步行动；没有学生作答时不猜测错因。AI 可能识别错数字、符号和图形关系，保存前应核对原题。

校对页先按题号切换，再用「题目 / 答案 / 解析 / 错因」查看对应内容，避免左右重复展示。长答案、解析和错因默认折叠，点击“展开完整内容”查看全文；原图、配图和知识点也可以按需展开。所有文本默认预览，点击“源代码”或双击预览可编辑，再切回预览检查公式。

只有明确的大题标题，或能在答案中对应的题号，才会自动分组；小问和普通步骤不会仅因带数字就拆开。未能对应题号的内容会提示从「全文」核对，共用说明单独折叠保留。单题编辑只更新该题正文，切换题号或分类不丢失修改。分类仅用于校对展示，保存仍包含整份识别结果；需要每题独立入库时，请在上传时使用多题框选。

展开「知识点」可分别修改 AI 返回的各题标签，每题最多 5 个，汇总自动去重并随题保存。没有逐题识别结果时保留整份标签，不自动猜分。旧题可点击「重新识别知识点」应用新的教材范围；整份重新标注会清除过时的逐题对应关系。教材目录依据与限制见[数学教材范围](../MATH_CURRICULUM.md)。

## 自动判重

导入时会与当前用户的已有题目比较题干，跨错题本参与判重。默认阈值为 90%，可在个人通用设置中调整。

- 相似度**严格大于**阈值时，返回已有题目，并在原题下记录一次做错。
- 相似度等于阈值时，不按超过阈值处理。
- 相似度是规范化题干后的字符编辑相似度，不代表数学含义相同。
- 重复导入记录参与后续掌握情况评估；需要核对时可查看原题的作答历史。

错题本还提供两题相似度比较，便于判断阈值是否适合自己的题目。数字或条件只改动少量字符时，相似度仍可能较高，应结合题意判断。

## 题目详情

每道题集中展示题干、答案、解析、知识点、难度、学期和卷别。拍照原图默认显示，宽屏时与题干并排且滚动时保持可见，也可点击放大。

| 信息或操作 | 说明 |
| --- | --- |
| 6 位题目 ID | 可复制，在错题本按 ID 定位；打印中显示为来源 ID |
| 1～5 星难度 | AI 参考竞赛数学难度标准评定，可手动修改 |
| A/B 卷 | 未指定时，1～3 星默认 A 卷，4～5 星默认 B 卷；已有手动选择优先 |
| 知识点 | 数学使用浙教版初二上候选清单，其他学科使用对应学段标签；支持单题或整本重新识别 |
| 重新生成完整解答 | 生成新的答案和解析，覆盖前会要求确认 |
| 修复 LaTeX | 检测到公式语法问题时出现，供 AI 修正公式写法 |
| 原题图片 | 可查看、替换或补充，用于核对识别结果 |

未评级的题目不会仅凭默认规则自动指定卷别。重新生成完整解答保留知识点和错因信息。

## 配图和动态讲解

- **SVG 配图**：由 AI 根据题目生成静态 SVG，供详情、练习和打印使用；原图可单独查看。
- **SVG 动画讲解**：首次打开题目时自动生成当前界面语言的动画，首次生成需要等待；之后直接播放已保存的版本，不重复调用 AI。支持暂停、进度拖动、重播和全屏。生成失败可手动重试，删除后本次查看不自动重建。默认开启，可在通用设置中关闭。

已生成的 SVG 动画可在确认后删除。生成的图形和解答需要人工核对，尤其是几何位置、计数过程和结论。

## 筛选与批量操作

可按掌握状态、知识点、时间、年级学期和卷别等筛选，再进行批量操作或打印。删除前确认筛选条件和选中范围；需要长期保存时先[备份数据](Backup-and-Restore)。

## Markdown 与公式

题目、答案和解析支持 Markdown，公式由 KaTeX 渲染：

```text
行内公式：$a^2+b^2=c^2$ 或 \(a^2+b^2=c^2\)
独立公式：$$\frac{a}{b}$$ 或 \[\frac{a}{b}\]
```

编辑时可在源代码与预览间切换。复杂表格和公式的写法见 [Markdown 指南](https://github.com/margrop/wrong-notebook/blob/main/doc/MARKDOWN_GUIDE.md)与[表格识别说明](https://github.com/margrop/wrong-notebook/blob/main/doc/TABLE_RECOGNITION.md)。
